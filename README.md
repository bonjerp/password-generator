# Password Generator

A simple password generator made with Python and PyQt6.

## Preview

![Password Generator](PasswordGenerator.gif)


## Installation

Download the latest version from [Releases](https://github.com/bonjerp/password-generator/releases), or run it from source.

### Running from source

Requires Python 3 and PyQt6.

```bash
git clone https://github.com/bonjerp/PassGen.git
pip install PyQt6
python main.py
```
